* Avaliaçaõ prática composta por atividades baseadas na projeto desenvolvido em sala de aula.
* Objetivo: Avaliar o dominio sobre conceitos basicos de atividades diarias de um desenvolvedor, 
    iniciando em uma empresa que recebeu a instrução de fazer o download de um projeto de estudo e,
    adequa-lo para uso e implementar algumas funcionalidades basicas.

### Regras prova
    - traga sua propria colo para os pontos que considere importante;
    - não e permitido o uso da internet;
    - não e permitido o uso de qualquer tipo de IA durante a avaliação;
    - A avaliação e individual, apos conclui-la, faça a entrega e se retire do local da aplicação;
    - o projeto inicial sera fornecido para o aluno;


### Padronização nome pasta e nome app :
    1. nome pasta para o projeto: **prova-p3-tecavan-<primeiro-sobrenome>**
        <nome> - aluno deve colocar o seu primeiro nome e sobrenome , ex.: **jose-silva**

    2. PORTA API : **3500** + 2 ULTIMOS DIGITOS RA
        <PORTA> - o aluno deve somar ao valor inicial 3500 o ultimos 2 digitos do seu Ra,
                exemplo : ra do aluno ultimos digito: 99 soma 3500 = porta ? 3599

    3. DATABASE : prova-n3-tec

    4. AMBIENTE VIRTUAL: myfimvida
